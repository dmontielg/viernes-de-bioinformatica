# Requirements

Before starting, please make sure you have the following accounts available.

## GitHub Account

A **GitHub account** is required for the course.

GitHub will be used to:

- Access the course repositories.
- Work with Git and GitHub.
- Use **GitHub Codespaces** as the development environment.
- Store and manage your own code during the exercises.

Create an account at: https://github.com/

## GitHub Codespaces

The course will use **GitHub Codespaces** to provide a ready-to-use development environment directly from your GitHub repository.

Make sure you can:

- Log in to GitHub.
- Access GitHub Codespaces.
- Create a Codespace from a repository.

No local R or VS Code installation is required when using Codespaces.

## Docker Hub Account

A **Docker Hub account** is required for the containerization and Docker exercises.

You can use your **GitHub account to sign up or log in to Docker Hub**.

Create or access your account at: https://hub.docker.com/

During the course, Docker Hub will be used to:

- Authenticate with Docker.
- Build and manage Docker images.
- Push images to Docker Hub.
- Pull images from Docker Hub.

## Docker Hub Personal Access Token (PAT)

You will need to create a **Personal Access Token (PAT)** in Docker Hub.

The token will be used instead of your Docker Hub password when authenticating from development environments such as GitHub Codespaces.

Make sure you have the following information available:

- Docker Hub username
- Docker Hub Personal Access Token (PAT)

> **Important:** Treat your PAT like a password. Do not add it directly to scripts, Dockerfiles, Git repositories, or commit it to GitHub.

## Pre-Course Checklist

Before the course starts, verify that you have:

- [ ] A GitHub account
- [ ] Access to GitHub Codespaces
- [ ] A Docker Hub account
- [ ] A Docker Hub Personal Access Token (PAT)
- [ ] Your Docker Hub username available
